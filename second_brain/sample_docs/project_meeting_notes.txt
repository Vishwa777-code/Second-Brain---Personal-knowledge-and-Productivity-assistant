Architecture Review
-------------------
- The app uses a coordinator pattern to route user requests to specialized
  agents (notes, tasks, email, research, knowledge base, briefing).
- LLM backend: Google Gemini (gemini-3.5-flash-lite) via LangChain.
- Vector store: ChromaDB with HuggingFace sentence-transformers embeddings.
- Database: SQLite for notes, tasks, email drafts, and conversation history.
- Frontend: Streamlit with tabs for chat, email, briefing, and stats.

Key Decisions
-------------
- Use SMTP (Gmail App Passwords) for email sending — simpler than full OAuth.
- Include mock inbox data so the app works in demo mode without live Gmail.
- Structured outputs via Pydantic models for email drafts and daily briefings.
- RAG pipeline uses recursive character text splitter with 800-char chunks.
